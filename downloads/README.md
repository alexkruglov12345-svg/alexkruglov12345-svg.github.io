# Office After Hours

Свежая Windows-версия игры с шестью сменами.

[Скачать игру из GitHub Releases](https://github.com/alexkruglov12345-svg/alexkruglov12345-svg.github.io/releases/tag/office-after-hours-2026-11-25)

После скачивания полностью распакуйте архив и запустите `ИГРАТЬ.bat`.

Управление: WASD — ходьба, Shift — бег, Ctrl — присесть, Пробел — прыжок, E — действие, F11 — полный экран.
